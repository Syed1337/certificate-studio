# What's new

## 1.3.0 (25 October 2026)

**Faster, more reliable start-up**
- Opens in under a second on most PCs. The start page is now 164 KB instead of 1.8 MB.
- Fixed: the app could stay on the loading screen, or open without some fonts, on PCs where security or ad-blocking software slows local connections. Fonts now load through the app itself, and loading retries automatically if anything stalls.
- Fixed: the close button now always closes the app. Work is still saved automatically after every change.

**New conference-style medals**
- New shapes: Milled coin, Double ring, Order star and Maltese cross.
- New ribbons: Striped neck ribbon and Long V tails.
- New finishes: Guilloche (fine security pattern) and Brushed metal.
- **Premium icons:** medal icons are now struck metal, like a real coin: solid gold relief with fine engraved detail, a soft glint and depth. On white or metal centres they are engraved. Choose *Struck metal*, *Metal line*, *Engraved* or *Flat line* under Medal → Centre → Icon finish.
- 10 new ready-made medals: Conference medal, Order of merit, Merit cross, Milled coin, Guilloche seal, Summit star, Modern ring, Laurel coin, Keynote medal and Platinum honour.

**Works completely offline**
- Fonts, designs, PDF/Excel tools and AI background removal are all built in. The only online feature is the update check, which you can now switch off in Help → About.

## 1.2.0 (13 October 2026)

- New award category **Tests & Quizzes**: Weekly Test Excellence, Weekly Test Topper, Monthly Test Excellence, Monthly Test Topper, Unit Test, Class Test, Quiz Champion, Mock Exam, Term Test, Full Marks, Most Improved in Tests and Consistent Test Performer, each with matching wording.
- Signatures: choose **Name + signature** or **Name only** for each person (School tab, or click the signature on the certificate). Name only prints the name on the signing line, no signature image needed.
- Help → Diagnostics now shows how long each start-up step took, to help track down slow starts.

## 1.1.0 (6 October 2026)

**New: Mac version.** Certificate Studio now runs on Mac (macOS 10.15 or later, Apple silicon and Intel). Download `Certificate-Studio-Mac.zip`.

- Mac menu bar with Copy, Paste, Select All and Quit, and ⌘ shortcuts shown throughout the app
- New website with downloads and step-by-step install help: https://syed1337.github.io/certificate-studio/
- Clearer first-time install instructions for the Windows "Windows protected your PC" message

## 1.0.1 (6 October 2026)

- Fixed: the app could stay on the loading screen. It now picks a free connection each time it starts, so a leftover copy of the app can no longer block it.
- If something still goes wrong while starting, a window offers **Try again** or **Start fresh** (your old work is kept as a backup) instead of an endless loading screen.
- Damaged saved data is repaired automatically.
- New: Help → Diagnostics shows any start-up problems to copy into a bug report.
- Note: after updating, the welcome screen appears once more.

## 1.0.0 (6 October 2026)

First public release.

- 53 layouts in 172 colourways, including 18 new sports, primary, science, luxury, classic and modern layouts
- Start screen with **New certificate** and **Continue where you left off**
- Office-style floating format bar: click any part of the certificate to edit it
- Layout, colour and font dropdowns above the certificate (scroll the mouse wheel to flip through them)
- 24 professional font pairings grouped by style
- Several school logos; choose which one the watermark uses
- Medal branches (laurel, olive, oak, palm, wheat, leaves, swirl) and top ornaments (stars, crown, sparkles, pearls, rays)
- Grade and place medals (A*, A+, A, 1st, 2nd, 3rd and your own text)
- Give any student their own design; scroll through every student's certificate
- Clean printing through your PDF viewer (no headers or footers)
- Faster start and saving; the app closes properly and saves your work first
- Update check: the app tells you when a new version is available
